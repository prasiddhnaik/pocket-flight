POCKET FLIGHT · VOL. 01

A little escape, ready to fly.

A self-contained React and TypeScript browser game with a custom Three.js aircraft, an authored tropical heightfield, aerodynamic flight, short missions, persistent medals, and procedural sound.

Open the game locally →

Run

bun install
bun run dev --port 5173

For a production build, run bun run build, then bun run preview. The output in dist/ can be served by any static web host. A keyboard and a WebGL 2 capable browser provide the best experience. Touch controls are also included.

Your first takeoff

Choose First light and hold Shift for full throttle. At around 45 knots, gently pull back with ↓ for about half a second. Release to trim. Fly through the first golden ring, then turn left around the mountain. For landing, approach at 55–65 knots, reduce power, lower the nose to descend, and flare gently above the runway. Hold B once down.

The first release

One Finch P–01 aircraft with five persistent paint schemes. Palm Bay has a 470-meter runway; Needle Point has a 245-meter strip. The islands include beaches, forest, palms, a coastal village, hangars, a tower, a lighthouse, docks, moving boats, clouds, birds, windsocks, runway lights, and a day/night setting.

Seven missions cover takeoff and landing, an island checkpoint tour, a canyon route, a short runway, engine-out gliding, a timed race, and crosswinds. Free flight has no deadline. Completed missions award scores and gold, silver, or bronze medals. The flight log and paint selection are stored locally in this browser.

The flight model runs at a fixed 60 Hz and includes aerodynamic lift and drag, angle-of-attack stalls, thrust falloff, inertia, sideslip damping, coordinated turns, wind, suspension, runway friction, and braking. Damage to gear, wings, propeller, and engine changes aircraft performance. Major impacts produce detached debris; the flight recorder retains up to 30 minutes for replay.

Download a replay

Pause a flight or finish a mission, then choose Download replay. The game plays the cinematic replay and saves a 1280 × 720 video as MP4 when supported, with WebM as the fallback. Engine and wind audio are included when sound is enabled. Keep the tab visible while the video renders; export takes about as long as the replay. Cancel returns to the paused flight or result without changing its state.

A Save video again link remains available after export. Resuming or restarting a flight clears that video so the next download includes the new flight history. Replays are held in memory until the page closes; downloaded videos remain on your device. Videos show the cinematic scene without the HUD. Recording is local and uses no microphone, screen-sharing permission, upload, or server.

Validation

Run bun test for the flight regression suite and bun run build for TypeScript and production compilation. Browser verification screenshots are in output/playwright/. The development server exposes window.pocketFlight for reproducible flight-state inspection; that hook is omitted from production builds.

Scope

This release uses an approachable assisted flight model, procedural component damage, and authored procedural scenery. It is not a certified flight-training model or a soft-body structural simulator. Replays preserve aircraft motion, propeller and landing gear state, detached parts, checkpoints, and the recorded world clock. Transient smoke is omitted from the cinematic replay. Equipment swaps beyond paint remain future work. Fonts may fall back to system fonts if the Google Fonts service is unavailable.

The project lives in its own pocket-flight/ directory. Existing Blender skill files were left untouched. The game has not been deployed to an external host.
