Finch U–2 engineering baseline

Physical force model implemented; aerodynamic accuracy remains provisional.
Finch now uses measured runtime wing geometry, body-frame airflow, forces in newtons, a conceptual mass budget, density-dependent lift and propulsion, induced drag, and an angle-of-attack stall curve. Beginner assist is on by default and can be switched off in Settings.

The user selected Finch as the first aircraft and physical flight with optional beginner assist. This work applies the aircraft-design handbook, especially sections 4, 5, 7, 8, 17, and 19. The existing asset is measured and tied to its force model. No new GLB or CAD rebuild is delivered in this milestone.

The measurement workflow integrates 800 midpoint sections per half-wing. It fills internal chordwise hinge gaps and retains spanwise gaps. Root fillets are merged into the exported paint mesh, so this reference-area convention explicitly includes them. This is a gross planform estimate, not an aerodynamic solver. Details and stations are saved in finch-geometry.json.

Conceptual loading and propulsion

These values are proposed engineering inputs for this fictional trainer, not measured masses or manufacturer specifications. The mass budget is explicit so it can be revised instead of hidden inside a lift multiplier.

The geometric ground-load estimate places approximately 27.2% of static weight on the nose gear at this CG. This only checks support geometry. The translation model uses loaded mass; the CG is recorded for the next moment-model milestone and does not yet change pitch stability.

Propulsion assumes 100 kW shaft power, 0.78 propeller efficiency, and a 2,750 N static-thrust cap. Thrust is bounded by both that cap and available power divided by airspeed. A naturally aspirated density correction is applied. The propeller model does not yet include an RPM/pitch efficiency map, slipstream, torque, or fuel consumption.

What now governs flight

BehaviorImplementationBoundary
AirflowWorld velocity minus wind, transformed into aircraft coordinates. α = atan2(−bodyVy, −bodyVz); β = asin(bodyVx / V).Whole-aircraft reference flow; local rotating-surface flow is not modeled.
Lift and accelerationq = ½ρV²; L = qSCL; aerodynamic force divided by loaded mass.Lift remains perpendicular to air-relative velocity; no speed-dependent lift-coefficient trim term.
DragCD = CD0 + CL²/(πARe), plus separation, sideslip, and damage estimates.CD0 = 0.032 includes Finch's fixed extended gear; e = 0.8 is assumed.
StallCL0 = 0.24, lift slope 5/rad, CLmax = 1.55, CLmin = −1.25. Continuous transition to a flat-plate estimate after critical α.Positive stall onset about 15.0°. These are estimated whole-aircraft coefficients; no validated custom-airfoil polar exists.
AtmosphereDry ISA tropospheric density at aircraft altitude, applied to dynamic pressure and engine power.Temperature departures and humidity are not simulated. HUD speed remains true airspeed.
AssistOptional self-leveling, coordinated-turn yaw, automatic pitch trim and scripted stall-recovery corrections.Disabling assist retains simplified rate-controlled pitch/roll/yaw. It is not a full unassisted six-degree-of-freedom simulation.

The equations follow NASA's lift equation and NASA's induced-drag relationship. These references support the relationships, not Finch's selected coefficients.

Repeatable workflow

  1. Run bun run finch:measure after any asset change. Reconcile dimensions, reference area, chord, and wheel datums with src/finch-design.ts.
  2. Revise the conceptual loading budget and propulsion assumptions, keeping units and provenance explicit.
  3. Run bun run finch:verify for force relationships, bank/wind invariance, stall, power limits, asset consistency, takeoff, landing, glide and damage.
  4. Run bun test --timeout 30000 and bun run build; distinguish pre-existing scenery failures from flight regressions.
  5. Fly the browser aircraft with real controls. Check assist persistence, takeoff, turns, recovery, approach and replay before approving handling.

Verification record

Focused Finch checks: 22 passed; the expanded flight, control-surface and replay set returned 39 passed. Production build passed with the existing large-chunk warning. The broader suite returned 80 passed and one timeout in the existing runway/terrain test; this test also timed out before the changes, and an isolated rerun still timed out. The browser loaded Finch and displayed the new assist control. Persistence and keyboard flight verification remain incomplete after the browser session returned to a blank page. This is not a completed gameplay acceptance test.

Remaining accuracy work

  1. Choose or substantiate airfoil sections and obtain Reynolds/configuration-specific polars. Validate wing incidence, twist/washout, and actual surface hinge geometry.
  2. Implement component force locations, CG-dependent moments, inertia, rotational damping, trim, and a declared stability model. Current rate controls are a simplification.
  3. Connect actual flap deflection and control-surface state to forces and moments; include propulsion spool/slipstream effects.
  4. Validate cruise trim, climb, glide ratio, turns, stall recovery, multiple loading cases and landing distances against a mission design sheet.

Peregrine, Aurelia, and Stormbird retain their legacy acceleration profiles. They now share the body-frame angle-of-attack correction and assist switch, but have not received Finch's physical sizing model. The civilian jet's shared afterburner profile remains outstanding fleet work.
