Fleet stall, stability and engine reference validation

2026-10-12T17:47:34.733Z · Local only · Publication held

All four aircraft were checked in the private tester's new flight-validation bench. The bench uses the shared flight model and game integrator; the separate inviscid main-wing vortex solver remains limited to attached flow. A worker runs these experiments away from rendering.

What changed

  • Finch altitude power now interpolates Lycoming's published normally aspirated engine table instead of multiplying by density. Rated shaft power, propeller efficiency, static thrust and throttle-power relation remain concept estimates.
  • Peregrine and Stormbird thrust now interpolates the NASA TP-1538 altitude/Mach deck. Its dry and maximum branches are independently scaled to existing concept ratings; dry rated command is 0.88, with a continuous afterburner transition. The source is a published simulator deck, not independently verified engine-test measurements. Below M=0.2 the first row is held; outside the source grid boundaries are held. This is not a manufacturer match to either fictional engine.
  • Aurelia's civil engine map remains estimated. The JT15D NASA research found in this pass concerns an instrumented inlet/noise installation and does not provide a matching installed engine deck for Aurelia. Its military afterburner branch remains absent.
  • Post-stall lift now transfers the approximate NACA 0012 experimental loss shape from Figure 2 of NASA TM-101413, normalized about each concept's own peak and critical angle. This is a shape surrogate, not measured CLmax or critical AOA for our planes. Deep-angle lift blends into the prior flat-plate estimate; negative-alpha symmetry is assumed.
  • Finch pitch damping uses the published Cessna 172 model value −11.4. The military jets use the angle-dependent Cmq table from NASA TP-1538. These are transfers across different geometry, CG, inertias and installations. The civil jet's pitch damping and all yaw/roll derivatives remain estimated. Separated flow reduces control effectiveness by an explicit estimated factor; it is not a measured tail-wake model.

Stability checks

Sixteen loading conditions each received pitch +2°, roll rate +5°/s and yaw +3° disturbances at trimmed speed and 1,000 m: 48 runs, 30 seconds each, zero wind, beginner assist disabled. The first and last five seconds of AOA/pitch-rate, roll-rate or sideslip/yaw-rate are compared by RMS. Every run stayed finite, damage-free and showed decay. This verifies these perturbations of the implemented model; it does not establish all phugoid, spiral, Dutch-roll or high-AOA modes from aircraft measurements.

Stall checks and the repeated-stall finding

Thirty-two engine-out hands-off probes start at trim speed with imposed AOA 10° beyond positive or negative stall onset, across four loading cases per aircraft. All exit the initial stall, but three Aurelia probes are stalled again at ten seconds. These are high-AOA release experiments, not one-g deceleration tests or proof of deep stall. A brief first exit is recorded separately from terminal state.

Sixteen powered positive-stall recoveries start at 1.1×clean stall TAS and 10° above onset. A declared test-pilot policy feeds bounded pitch commands (−0.25 to +0.15) toward 60% of critical AOA with pitch-rate damping and advances power. The game's beginner assist stays disabled. Every ten-second run recovers and stays clear of stall for at least 9.22 seconds at the end, with no damage. Existing automatic gear/flaps remain active; this is not a manual fixed-configuration certification test.

Longer exploratory powered runs hit the existing 1,800 m position/vertical-velocity clamp in src/physics.ts, which can alter airflow and create apparent restalls. The reported recovery window ends before that boundary (maximum height 1467 m). The clamp requires separate engine-architecture work; do not use boundary-contaminated trajectories as aerodynamic evidence.

Engine checks

480 fleet samples cover 0/1,000/3,000/6,000 m, M=0/0.1/0.2/0.4/0.6/0.8, and commands 0/0.25/0.5/0.88/1. Monotonic command, finite non-negative output, zero-command cutoff, altitude loss and reference grid anchors/intermediate interpolation pass. The 3,000/6,000 m samples are static engine-map inspections beyond the game's flight ceiling, not flights at those altitudes. Propeller efficiency at high Mach, civil installed thrust, fuel flow, engine transients and idle net drag remain unvalidated.

Primary sources and applicability

Lycoming O-360 (76 series), 60297-25, June 2007

Manufacturer reference table; standard conditions, not an installed propeller map

NASA TP-1538, Nguyen et al., December 1979
Table VI (printed p.93, PDF p.99); Table III Cmq (printed p.66, PDF p.72)
Published simulation thrust deck; low-speed subscale wind-tunnel aerodynamic data. Engine deck is not independently established as measured engine-test data

NASA TM-101413, Wu et al., 1989
Figure 2, printed p.5 / PDF p.7; circular experimental markers only
NACA 0012 section experiment reproduced from McAlister et al., NASA TM-84245; M=0.3, Re=3.9 million. Approximate visual transcription ±0.05 CL, ±0.5 degrees

NASA CR-2605, Roesch and Harlan, October 1975
Appendix A, Table A-1, printed p.77
Cessna 172 model: DATCOM estimates and borrowed rotary derivatives; wing lift slope checked against model wind-tunnel test. Cmq=-11.4 is a published model value, not a Finch measurement

NASA TN D-6573: full-scale unpowered executive T-tail jet provides measured configuration-dependent high-AOA pitch-up, buffet and possible deep-stall trim. Its different sweep, airfoil, high-lift devices and tail installation prevent direct transfer to Aurelia. It establishes a missing test requirement; it does not prove our current repeated stall is that phenomenon.
