Object placement in Scene Studio

The Object inspector now measures the selected model and provides three commands: place it beside the aircraft, set its largest dimension in meters, and place it on terrain or runway ground. Edits use the existing transform, keyframe, undo, and save paths.

Repository: pocket-flight · local working tree based on 249032d · implemented locally; no commit or deployment performed.

Using the tools

Open a recorded flight in Replay Studio. Pause playback, select a visible model in Scene mode, and use the new Placement section in the Object inspector.

1. LocateChoose Place beside aircraft. The object moves near the current aircraft pose and the viewport frames it.
2. SizeRead W/H/D, enter the desired largest dimension in meters, and choose Apply size.
3. GroundFor a World-anchored object, choose Place on ground. Its bottom bound moves to the highest sampled ground height.

Set size before grounding: resizing a centered model later can move its base above or below the ground. Ground placement is a command at the current moment, rather than a persistent constraint.

Technical behavior

CapabilityImplemented behaviorBoundary
DimensionsMeasures visible mesh bounds at the evaluated pose; displays width, height, and depth to three decimal places. Child transforms, scale, rotation, current skinning, instancing, and morph pose are included.Dimensions use world axes for World objects and aircraft-local axes for Aircraft objects. They describe an axis-aligned bound, so rotation can change the values. Animated models can change dimensions over time.
Place beside aircraftUses offset [8, 2, 0] in the rendered aircraft's local axes. For World objects, rotates this offset by the aircraft quaternion, adds its position, then subtracts the project origin. Aircraft objects receive that local offset directly.Preserves anchor, rotation, and scale. The offset follows bank and pitch as well as heading. It does not solve collisions with the aircraft or scenery.
Apply sizeMultiplies all existing scale components by target / largest measured dimension. Preserves existing relative scale ratios, position, and rotation.Rejects empty dimensions, nonfinite or nonpositive targets, and resulting scale components outside 0.001–10000. The target uses the current pose, not an animation-wide envelope.
Place on groundSamples groundAt(x, z) on a 5 × 5 grid covering world-space bounds. Moves Y by highest sampled height − bottom bound. Ground sampling includes terrain and runway/apron elevations from the existing ground model.World objects only. Preserves X/Z, rotation, and scale. It does not place onto imported models, building roofs, or arbitrary scene surfaces. Uneven ground and narrow features between sample points can leave gaps or intersections.
Edit history and persistenceCommands commit through the existing pose-edit path. A static object updates its transform; an object with keys, or with Auto Key enabled, receives a key at the playhead. Existing undo/redo and browser saves apply.No project schema or backup format was changed. A placement key uses existing smooth easing behavior.
Readiness and locksControls wait for a loaded, measurable model and a paused, editable scene. Locked and hidden objects cannot be placed; lights do not provide mesh dimensions.Ground placement is disabled for Aircraft anchors. Export, loading, and transform dragging prevent placement commands.

Coordinate and measurement flow

The UI asks the preview to render the exact current film playhead before applying a command. This ensures the aircraft pose, object transform, and embedded animation agree at measurement time. The preview obtains the selected renderer instance and delegates geometry calculations to a small placement module.

Object inspector → ReplayStudio.placeObject
  → render current playhead
  → ReplayPreview.placeObject
  → boundsInFrame / fitObjectSize / placeBesideAircraft / placeOnGround
  → changeObjectPose → existing history + project save

For a point v in a child mesh:
  anchor-space point = inverse(anchor matrix) × mesh world matrix × v

For ground placement:
  nextY = currentY + max(25 ground samples) − worldBounds.min.y

Regular static mesh bounds reuse the geometry bounding box. Morph meshes measure their evaluated vertices; skinned and instanced meshes compute their object bounds. Dimensions refresh with inspector updates about ten times per second. Large animated models may make these calculations more expensive; no performance benchmark for such assets was run.

Repository state and useful next work

The repository already contained separate aircraft, effects, world, asset, and test edits. They were preserved. This report describes the placement module, inspector integration, styling, and placement tests only; it does not claim the entire dirty working tree is validated.

The next useful scene-assembly upgrade is multi-selection with batch transforms: select several props, move or duplicate them together, and apply shared visibility timing. Persistent terrain contact and exact surface picking would require additional behavior beyond these three placement commands.
