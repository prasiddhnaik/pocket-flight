Scene Studio: separate editing operations and views.

The current pocket-flight-site/ checkout on codex/private-wind-tunnel now separates Studio's project-editing operations and UI panels from its session coordinator. Gameplay code, styles, project schemas, and browser storage contracts were preserved.

What changed

Module Responsibility after the split
ReplayStudio.tsx
1,803 → 1,163 lines 		Session state, command wiring, selection, undo/redo, save queuing, preview lifecycle, playback, import coordination, and export. It composes the views and commits the results of editing operations.
studio-editing.ts
219 lines 		Clip edits, splitting/reordering/duplication/removal, camera clock conversion, camera/object anchor conversion, object duplication, and spawn position. Inputs are project data; outputs are edited data. New identities are generated for duplicates and split clips. The module does not render, persist, or control playback.
panels/
14 files; largest 234 lines 		Asset browser, outliner, object/camera/project/clip inspectors, saved flights and projects, timeline, transport, scene tools, and export status. fields.tsx contains shared numeric/vector controls and the existing close icon. The old 887-line StudioScenePanels.tsx has been replaced by direct imports of these modules.
studio-format.ts
9 lines 		The existing time, filename, and error-message formatting used by the extracted views.

This is an incremental split. Playback/export lifecycle and persistence remain together in the coordinator. Moving those would require a separate lifecycle-focused change; they were not rewritten merely to reduce the file's line count.

How to work on Studio next

  • For a panel's presentation or input controls, begin in panels/. Keep project commits and asynchronous lifecycle coordination in the parent.
  • For clip/object transformations, use studio-editing.ts and its tests. Preserve source time versus film time and avoid mutating the input project.
  • For schemas or portable backups, inspect studio-model.ts, studio-scene.ts, studio-assets.ts, and replay/replay-library.ts. Their formats were unchanged in this pass.
  • For playback, export, cancellation, or save-queue changes, trace the coordinator's effects and refs before extracting another module.
