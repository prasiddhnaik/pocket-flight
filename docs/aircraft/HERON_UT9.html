Design brief

The requested rule is that every part connects physically to the body and the aircraft looks realistic. The selected design is a single-engine utility turboprop inspired by the Grand Caravan class: a long cabin, high cambered wings with lift struts, a conventional tail, sturdy fixed gear and an underbody cargo pod. It is an original game asset; proportions and power class are referenced, while detailed stations, component masses and flight coefficients are authored estimates.

Build workflow

Use bun run heron:build to build the CAD master, validate exact-solid connections, tessellate those same solids, export the game GLB and refresh Heron’s own measurements. Use bun run heron:check for focused asset and flight tests. No existing aircraft asset is regenerated by this workflow.

The isolated authoring environment is assets/heron/.venv. Its pinned dependencies are in assets/heron/requirements.txt; it does not change the existing shared CAD environment. Set HERON_PYTHON to use another interpreter with those dependencies. Authoring files follow the repository’s existing ignored-assets convention; the runtime GLB and CAD validation manifest live under public/assets/.
