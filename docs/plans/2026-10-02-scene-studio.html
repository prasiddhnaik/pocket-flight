Scene Studio

2 October 2026. Build directly, without subagents, as requested.

Outcome

Extend the replay video editor with Blender-style scene assembly: bring in local assets, arrange and animate objects, direct cameras, mix imported audio, and render the composition into a saved video. Flight replays remain the footage source. Preserve existing projects and original aircraft recordings. Do not test jets.

Workflow Implementation
Assets GLB, glTF with selected companion files, OBJ, STL, PNG/JPEG/WebP, and audio. Import through file selection or drop; keep asset files in IndexedDB. Support geometry, textures, and embedded GLB animations. Explain unsupported compressed assets and missing dependencies.
Scene assembly Outliner, primitives, visible/hidden and locked objects, duplicate/remove, position/rotation/scale, world and aircraft anchors, material tint and lighting. Mouse selection, orbit navigation, move/rotate/scale gizmos, snapping, framing, and undo.
Animation Object transform keyframes with linear, smooth, and hold interpolation. Timeline visibility ranges and key markers. Custom camera keys from the free viewport, position and target controls, lens/FOV, aircraft/world camera anchors. Deterministic samples while scrubbing and exporting.
Audio and export Imported soundtrack layers with offsets, volume, looping, and fades, mixed with game audio. 720p and 1080p export. Hide all editing helpers during render. Preload assets and audio before recording.
Persistence Upgrade the browser database with an asset store. Projects contain asset references and edit decisions. Portable project backups package referenced asset bytes; restore atomically. Maintain compatibility with existing replay-only projects.

Execution

  1. Pure scene schema, interpolation, key editing, asset validation, and migration/backup tests.
  2. Local asset loaders, scene renderer, transform controls, viewport picking, and camera sampling.
  3. Outliner, asset browser, scene inspector, key timeline, keyboard tools, audio controls, and rendering options.
  4. Build and focused tests, then Finch-only browser verification with actual imported assets, reload, backup restore, manipulation, animated preview, and export inspection.
  5. Commit and push only this feature, retaining unrelated aircraft/performance edits.

Structure

studio-scene.ts owns data and deterministic sampling. studio-assets.ts owns file bundles and portable backups. studio-scene-renderer.ts owns imported model instances. studio-soundtrack.ts owns audio scheduling and mix capture. Modular React scene panels plug into the existing editor. Existing replay library, preview, project validation, and export receive focused extensions.

Boundaries

This is a browser scene editor for replay films. Mesh modeling, sculpting, arbitrary Blender Python execution, and .blend parsing are outside the implementation. Use Blender's GLB/glTF exports to transfer assets. Video export runs in real time in a visible tab. Browser storage remains local to the site origin.
