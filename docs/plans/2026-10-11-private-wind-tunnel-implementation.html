Private wind tunnel implementation plan

11 October 2026 · Approved design · Native execution in this chat

Goal: a local geometry-based aerodynamic test lab for Finch, Peregrine, Aurelia and Stormbird, with a modeled tunnel and traceable numerical evidence. Architecture: independent Vite entry; pure TypeScript horseshoe-vortex wing solver; React controls and plots; Three.js model/flow inspection; editable Blender environment. Stack: Bun, TypeScript, React, Three.js, Blender.

Approved design. The user approved the design and instructed implementation. Execute directly; user instructions prohibit subagents. Do not wire this tool into game navigation or deployment.

Global constraints and review focus

  • Metres, seconds, kg, newtons; X right, Y up, Z aft/downstream. Clear units and result provenance.
  • Wing-only, steady incompressible attached flow; no fabricated stall, parasite drag or wall corrections.
  • Reject nonfinite/out-of-range inputs and malformed geometry; show diagnostic errors.
  • Use actual exported wing datums. Preserve game assets and existing development changes.
  • Validate solver sign, symmetry, ideal-wing benchmark, discretization convergence and residual.
  • Check resource disposal, responsive controls, exports, and WebGL errors in the browser.
