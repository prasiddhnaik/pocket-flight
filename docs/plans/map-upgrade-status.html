Pocket Flight: detailed coastal scenery

3 October 2026 · Implemented in Blender 5.2.1 LTS and integrated into flight and replay scenes. This is a substantial realism upgrade; it remains a browser game rather than a fully photorealistic environment.

What changed

AreaDelivered
Village588 editable cottage components: board-and-batten siding, closed gables, roof folds and caps, fascia, framed recessed glazing, louvred shutters, panelled doors, handles, porch decking, posts, rails, stairs, deep piers, gutters, downpipes and rain tanks. Verification

The production build passes. Six focused scenery and asset tests pass with 611 assertions. They check both runway/apron plateaus, path clearance, exported terrain against simulator ground at 42 sample points, geometry presence, download budgets, dark basalt color, and distant-tree triangle count. An earlier run exceeded Bun's default five-second per-test timeout while the graphics scenes were active; the same focused tests passed with an explicit 30-second timeout.

Browser review covered village, hangars, coast, forest and overview, including daylight/evening transitions and console warnings. A brief Finch free-flight render was inspected. No jet flight or jet physics tests were performed. Local preview build success and observed frame rates do not establish performance on every device.

Every runtime GLB is below 8 MiB. Source scans were downloaded from Poly Haven with matching MD5 checksums. Final exported files have SHA-256 entries in public/assets/scenery/manifest.json.

Blender source and rebuild workflow

Editable packed source: assets/palm-bay-coastal-kit.blend. Original GUI draft is retained in a hidden collection. Editable house/hangar collections retain individual components; consolidated runtime collections provide the exports. Scan materials are packed so the source can move to another machine.

bun scripts/fetch-coastal-references.ts
bun scripts/export-island-heightfield.ts

In Blender, set POCKET_FLIGHT_ROOT to the checkout if needed, execute scripts/build-coastal-assets.py, then call rebuild_assets(). This rebuilds only the kit's named output collections and retains other scene content. The image-generated cloud is a checked-in runtime asset, so rebuilding does not require an image API call.

References and rights

  • Library of Congress: Lihue Plantation House, HABS HI-59 and HAPCo House No. 26-4, HABS HI-559 inform the timber construction and proportions. The cottages are original adaptations, not exact reproductions of those buildings.
  • NPS Kalaupapa geology and USGS Hawaiian volcano evolution inform erosion and coastal formations.
  • Island Tree 02 and Coast Rocks 05 are modified CC0 Poly Haven assets. Pale limestone is distinct from the original basalt geometry.
  • Research used Exa and Parallel Search. OpenAI image generation supplied a concept board and the transparent cloud sprite. The concept board is visual direction, not a screenshot of the implemented map.

Scope

Only map assets, integration, loading gates, the viewer, rebuild workflow and focused verification are included in this update. Existing unrelated aircraft, heat effects and rendering edits are preserved in the working tree.
