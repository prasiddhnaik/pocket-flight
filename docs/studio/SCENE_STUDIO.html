POCKET FLIGHT · EDITOR GUIDE

Build a film around your flight.

Scene Studio combines saved flights with imported models, image planes, animated props, camera paths, and custom audio. Open Replay studio from the game's home or pause menu.

1. Assemble the flight

Add saved flights from the Flights tab. Select clips to trim source seconds, change playback speed, choose camera shots, and add titles. Split, duplicate, and reorder clips. The flight recording remains intact; this film stores its own copy.

2. Bring your own assets

Open Assets and choose Import your assets, or drop files into the editor. Imported items enter the asset library and the current scene. Select an asset's Add button to place more instances.

Asset Supported workflow
Blender models Export glTF 2.0 as .glb with textures and animations embedded. Use uncompressed output. GLB is the simplest portable format.
glTF files Select the .gltf, referenced .bin buffers, and textures together. References must resolve to selected local files.
Geometry .obj and .stl. OBJ imports geometry and embedded vertex colors; separate MTL files are not loaded.
Images PNG, JPEG, WebP become 3D image planes with their original aspect ratio.
Sound WAV, MP3, OGG, M4A, AAC, FLAC when the browser can decode the format.

Imports are limited to 128 MB per batch. Models are centered and normalized to a 6 meter maximum dimension; use Scale to set the final size. Imported files stay in this browser and are not uploaded to a server.

3. Arrange the scene

Select in the Scene outliner or click a model in Scene mode. Move, rotate, and scale using the viewport gizmo or numeric Object fields. Objects can stay fixed in the world or follow the aircraft. Position uses meters, rotation uses degrees, and Y points up. World coordinates use the first film clip's initial aircraft position as their origin.

Use F to frame the selected object. Drag empty viewport space to orbit, right-drag to pan, and scroll to zoom. Snapping uses 1 meter, 15 degree, and 0.1 scale increments. The outliner offers hide, lock, duplicate, and undoable removal. Add cubes, spheres, cylinders, rings, planes, and point lights from Assets.

4. Animate objects

Move to a film time and choose Key at playhead or press I. Move to another time and change the transform to add the next key. Once an object has keys, subsequent transform edits update the key at the playhead. Auto keyframes also creates keys on an object that has none. Choose smooth, linear, or hold easing for each key. Scene tracks show key positions and visibility intervals.

Imported GLB/glTF animation clips appear in Object → Embedded animation. Choose a clip, set its speed, and toggle looping. Scene animation follows film time, including scrubbing.

5. Direct the camera

Choose Scene mode, orbit to compose a shot, and choose Camera key. Move to another time, adjust the view, and capture again. The Camera tab also edits camera position, target, field of view, and easing. Camera keys use the original recording's source seconds, so they follow clip trimming and playback speed. Track the aircraft or anchor the camera in the world. Rendered preview shows the camera path without editing helpers.

6. Mix and render

The Project tab sets exposure, recorded/day/night lighting, 720p or 1080p resolution, and a 30 or 60 fps capture target. Audio layers have film start/end times, source offsets, volume, looping, and fade controls. Imported audio mixes with engine and wind audio in the exported video.

Choose Export video and keep the tab visible. Export runs in real time; actual frame rate depends on browser and hardware performance. The browser chooses MP4 when supported, otherwise WebM. Watch the finished export inside the editor or save it using the download link.

7. Save and move a project

Projects, flights, and original asset bytes save automatically in IndexedDB. The Backup button creates a .studio.json containing the film, embedded flight recordings, and all referenced assets. Restore it using the backup picker. Existing replay and older project JSON files remain supported. Keep a backup before clearing browser/site data.

Shortcut Action
G / R / S Move / rotate / scale
F / I Frame object / add transform key
Shift D / Delete Duplicate / remove selected object
Space Play or pause the film
⌘ Z / ⇧ ⌘ Z Undo / redo

Scene Studio edits replay scenes. It does not load native .blend files or provide Blender's mesh editing, sculpting, simulations, compositing nodes, or Python runtime. Create those assets in Blender, then export GLB for placement and animation here.
